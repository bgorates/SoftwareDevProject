Hospital Appointment & Patient Management System

This system is designed to simplify hospital operations by providing an online platform for patients, doctors, and administrators. Patients can easily book and manage appointments, doctors can access schedules and medical records, and administrators can manage hospital resources efficiently.

Functional Features
	•	Patients can register, search for doctors, and book/cancel/reschedule appointments.
	•	Doctors can view daily schedules, access patient histories, and record diagnoses/prescriptions.
	•	Administrators can manage doctor profiles, departments, and generate reports.
	•	System validates appointment conflicts and ensures proper scheduling.
	•	Automated notifications (SMS/email) remind patients of upcoming appointments.
	•	Medical records are stored and accessible based on role permissions.

Non-Functional Features
	•	Performance: Fast response times for booking and searching appointments.
	•	Scalability: Able to handle a high number of concurrent users during peak hours.
	•	Security: Protects sensitive medical data with role-based access and encryption.
	•	Availability: Minimal downtime, especially during working hours.
	•	Usability: Simple, intuitive interface for patients, doctors, and admins.
	•	Reliability: Ensures data consistency and prevents double-booking.
